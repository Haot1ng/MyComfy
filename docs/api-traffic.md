# API 流量和两层限流

在管理后台打开 **API 流量**，本机默认地址为 `http://127.0.0.1:8001/traffic.html`。列表来自本次部署注册的业务和管理 API，包含尚未收到请求的接口。相同方法和路径模板归为一行，例如不同任务 ID 的详情请求合并统计。页面和静态文件不计入 API 流量。

## 如何设置

1. 搜索方法或路径，例如 `prompt-assist`，点击该接口的“编辑规则”。
2. 设置网关的每 IP 每分钟请求数、额外突发数，以及该接口支持的 Core 限额。保存后 Core 按数据库中的新规则处理后续请求。Nginx 校验新配置并热加载，页面出现“网关已同步”后，该版本已由网关确认。已建立的 SSE 可继续接收事件，热加载后旧 Nginx 工作进程最多保留 1 小时。
3. 点击“恢复默认”可撤销该入口的自定义值。规则保存在 MySQL，重新部署后仍然有效。

| 接口 | Nginx 每 IP 每分钟 | 额外突发 | Core 每用户每分钟 | 每服务商并发 |
| --- | ---: | ---: | ---: | ---: |
| 常规已鉴权业务 API | 600 | 60 | 120 | — |
| 注册 | 30 | 5 | — | — |
| 登录、退出会话及管理 API | 600 | 60 | — | — |
| 提示词扩写 | 60 | 10 | 12 | 4 |

**第一层在 Nginx。** 来源 IP、监听入口、HTTP 方法和路径模板共同决定额度。Nginx 按配置速率持续补充额度，允许额外突发请求立即通过，超出时返回 `429 EDGE_RATE_LIMIT`。每分钟请求数为 0 时关闭该接口的入口限流。突发数为 0 时仍按设定速率放行，不提供额外突发额度。

**第二层在 Core。** 鉴权通过后，同一个账号从不同设备访问同一接口共用一个 60 秒计数窗口，超出时返回 `429 USER_RATE_LIMIT`。提示词扩写另外对正在使用的服务商配置限制同时在途的调用数。假设并发上限为 4，四位用户正在扩写，第五个调用会收到 `429 PROVIDER_CONCURRENCY_LIMIT`。已有调用结束释放名额后即可再试。两种限额可分别设为 0 关闭，429 响应均带有 `Retry-After`（秒）。登录接口已有的账号和来源频率限制和任务重试次数各自独立。

一键部署使用 Redis 共享用户计数和并发占位。已配置的 Redis 暂时不可用时，需要该层限流的请求返回 `503 RATE_LIMIT_UNAVAILABLE`。直接启动单进程开发服务并省略 Redis 地址时，计数保存在进程内存中。

## 流量统计的口径

- 页面可见时每 15 秒更新一次，支持暂停或手动刷新。编辑规则期间保留输入。
- 选择最近 5 分钟、15 分钟、1 小时或 24 小时。平均每分钟请求数为该窗口请求量除以分钟数。表格可查看 4xx、5xx、平均及最大耗时和各层拒绝数。
- 网关从首次启用时开始采集，按请求完成的分钟汇总。跨越升级时间的统计窗口只显示启用后的网关请求，启用前的记录可在“请求审计”查看。网关直接返回的 429 和连接 Core 失败的 5xx 也会计入。SSE 长连接在关闭后计入，耗时包含整个连接时间。
- 总请求数取一个来源，经过两层的同一请求只计一次。网关统计库不可读时页面改用 Core 审计，并标明缺少入口数据。网关同步状态和最后回报时间可用于判断数据是否仍在更新。
- 管理员刷新流量页也是一次管理 API 请求，完成后会出现在后续统计中。网关记录的路径使用模板，日志不记录提示词、Cookie、查询串、账号或来源 IP。

## 反向代理和来源 IP

默认按直接连接 Nginx 的对端地址计数。多人通过同一上游代理进入时可能共用一个 IP 额度。上游代理确实提供可信的客户端转发地址时，可在部署配置 `public.trusted_proxy_cidrs` 填写紧邻网关的受信代理地址或 CIDR，再重新部署业务端。只填实际受控的代理；来自其他对端的转发头会被忽略。用户级限额始终按已登录账号计算。

## 管理 API

`GET /local/v1/traffic?window_minutes=15` 返回两个监听入口的路由目录、有效及默认规则、各项统计和网关状态，支持 1 到 1440 分钟。`PUT /local/v1/traffic/rules` 完整替换某一接口的规则。下面的例子把每用户扩写频率降至每分钟 6 次，并允许同一服务商同时处理 2 个扩写请求。

```json
{
  "listener": "public",
  "method": "POST",
  "path": "/api/v1/strategy-versions/{version_id}/prompt-assist",
  "rule": {"edge_rpm": 60, "edge_burst": 10, "user_rpm": 6, "provider_concurrency": 2}
}
```

用同一监听入口、方法和路径提交 `"rule": null` 即可恢复默认值。浏览器管理页使用同源管理通道，已配置的 HTTPS 管理域名提供相同操作。[管理 API](web-api.md)
