# MyComfy 管理后台

启动 `mycomfy api --port 8000 --local-port 8001` 后，在服务所在机器打开 [本机监控](http://127.0.0.1:8001/)。监控视图从同源的 `/local/v1/monitor` 读取数据，模板维护使用侧栏中的“工作流模板”。

总览展示队列、等待、重试、隔离、发布积压、容量和告警。请求审计提供可关联的目标 ID，批次详情可定位到任务，任务可查看执行历史、文件和日志，执行可追踪到实例代次与 GPU 采样。总览及实例页在可见时每 10 秒刷新，可手动暂停。列表使用服务端游标，可组合对象 ID 与时间范围筛选。浏览器后退或前进会恢复对应筛选和分页位置。

本机地址和启用的 HTTPS 测试地址提供同一套管理页面，打开后台即可查看监控。采样与告警由服务独立运行。[前后台 API](../../docs/web-api.md) · [运维说明](../../docs/operations.md)

## 用户管理

在侧栏打开“用户管理”，可以翻页查看全部账号的用户名、ID、分组和生效权限。选择一个用户，勾选要保留的全部分组并保存。一个账号可以加入多个组，清空勾选会撤销该账号的全部组权限。改动保存后，该用户的下一次业务请求即按新权限执行，刷新工作台可更新可见按钮。[打开用户管理](http://127.0.0.1:8001/users.html) · [分组维护 API](../../src/mycomfy/api/group_admin.py)

启用公网 Admin 链接后，任何拿到该链接的人都能看到全部账号并修改任意用户的分组。创建分组或修改某个组包含的权限点，使用带 Bearer 凭据的维护 API。[权限组定义](../../docs/operations.md#用户分组)

## 新增模板

1. 在业务机浏览器进入“工作流模板”，点击“新增模板”，填写工作台显示的名称和唯一标识。例如可以把“商品首帧短片”的标识设为 `product-i2v`。[打开工作流模板](http://127.0.0.1:8001/templates.html)
2. 选择工作流来源。基于内置 H3 创建时会沿用已有的输入绑定、模型要求和视频输出。也可以导入自己从 ComfyUI 导出的 API 工作流 JSON，点击“读取节点”，再用“添加输入”为需要在工作台填写的参数选择节点和输入字段。例如把提示词绑定到文本输入，把首帧素材绑定到图像加载节点的 `image`。选择保存视频的节点、文件名前缀输入及视频类型。
3. 预览新模板，点击节点核对参数、连线和输出，确认后发布。本机管理页直接提交，新标识首次发布为 `v1`。如果标识已存在，页面会提示更换标识。
4. 返回“选择模板”，可按卡片上的标识、名称和版本核对结果。打开用户工作台的“创建批次”，在“生成策略”中选用新模板。[打开用户工作台](http://127.0.0.1:8000/#/create)

能够使用业务机本地管理入口的用户均可发布模板，页面无需选择维护凭据文件。显式启用外网后台测试链接后，任何拿到链接的人也能查看监控、预览和发布模板。[分享测试链接与关闭入口](../../docs/https-tunnel-test.md)

## 导入模板

在“打开 JSON 文件”旁点击“查看 JSON 示例”可以预览、复制或下载一份可直接导入的 H3 文生视频模板。示例包含工作流、输入绑定与输出定义，省略了可选的扩写指令。已有完整 MyComfy 策略 JSON 时，打开文件或粘贴 JSON，预览后点击“发布新版本”。内置的 H3 文生视频和图生视频也可直接发布。同一标识每次执行“发布新版本”都会递增版本号。

“选择模板”列出所有已发布模板，每个标识显示当前最新版本。点击卡片会从数据库读取该版本的完整工作流并展示节点与连线。从文件、粘贴或维护 API 发布的模板都会列入目录。尚未发布的内置模板以“内置”标记，可直接选用。

ComfyUI 编辑器保存的画布 JSON 可用于查看节点和子图。要基于它新增模板，请在 ComfyUI 中导出 API 格式的工作流。[策略发布接口](../../docs/web-api.md#本机维护)


## 配置提示词扩写

1. 在“提示词服务商”添加一个兼容 OpenAI Chat Completions 的服务，填入基址、模型标识和服务需要的 API 密钥，保存后点击“启用”。可随时在已保存的配置之间切换。
2. 在“工作流模板”选中已发布的模板，打开“为此模板启用提示词辅助”，填写“给 AI 的编写要求”，勾选允许扩写的字段，点击“保存扩写设置”。取消启用后保存即可关闭。
3. 新规则从下一次扩写生效。同一模板系列共用后台设置，各版本只启用自身支持的文本字段。上传时省略指令的模板也能随时开启。工作台用户仍可直接提交原文。
