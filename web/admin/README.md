# MyComfy 本机管理后台

启动 `mycomfy api --port 8000 --local-port 8001` 后，在服务所在机器打开 [本机监控](http://127.0.0.1:8001/)。监控视图从同源的 `/local/v1/monitor` 读取数据，模板维护使用侧栏中的“工作流模板”。

总览展示队列、等待、重试、隔离、发布积压、容量和告警。请求审计提供可关联的目标 ID，批次详情可定位到任务，任务可查看执行历史、文件和日志，执行可追踪到实例代次与 GPU 采样。总览及实例页在可见时每 10 秒刷新，可手动暂停。列表使用服务端游标，可组合对象 ID 与时间范围筛选。浏览器后退或前进会恢复对应筛选和分页位置。

监控页面通过本机入口免登录只读访问。API 校验连接对端、Host 和 Origin。采样与告警由服务独立运行。[前后台 API](../../docs/web-api.md) · [运维说明](../../docs/operations.md)

用户分组由本机维护程序通过带凭据的 API 管理。维护 API 提供权限清单、用户的分组与授权查询、分组创建及修改接口。[分组维护 API](../../src/mycomfy/api/group_admin.py)

## 新增模板

1. 在业务机浏览器进入“工作流模板”，点击“新增模板”，填写工作台显示的名称和唯一标识。例如可以把“商品首帧短片”的标识设为 `product-i2v`。[打开工作流模板](http://127.0.0.1:8001/templates.html)
2. 选择工作流来源。基于内置 H3 创建时会沿用已有的输入绑定、模型要求和视频输出。也可以导入自己从 ComfyUI 导出的 API 工作流 JSON，点击“读取节点”，再用“添加输入”为需要在工作台填写的参数选择节点和输入字段。例如把提示词绑定到文本输入，把首帧素材绑定到图像加载节点的 `image`。选择保存视频的节点、文件名前缀输入及视频类型。
3. 预览新模板，点击节点核对参数、连线和输出，确认后发布。本机管理页直接提交，新标识首次发布为 `v1`。如果标识已存在，页面会提示更换标识。
4. 在“已发布模板”中核对该标识和版本。打开用户工作台的“创建批次”，在“生成策略”中选用新模板。[打开用户工作台](http://127.0.0.1:8000/#/create)

能够使用业务机本地管理入口的用户均可发布模板，页面无需选择维护凭据文件。业务机对本地用户的访问权限决定谁可以执行这项操作。

## 导入模板

已有完整 MyComfy 策略 JSON 时，在“工作流模板”中打开文件或粘贴 JSON，预览后点击“发布新版本”。内置的 H3 文生视频和图生视频也可直接发布。同一标识每次执行“发布新版本”都会递增版本号。

ComfyUI 编辑器保存的画布 JSON 可用于查看节点和子图。要基于它新增模板，请在 ComfyUI 中导出 API 格式的工作流。[策略发布接口](../../docs/web-api.md#本机维护)
